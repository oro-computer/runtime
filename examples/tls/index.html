TLS Echo Examples

These demos exercise the oro:tls module with a minimal echo server and client. The scripts run in the Oro Runtime via the CLI, and include an optional mutual TLS (mTLS) pair.

Prerequisites

  • Desktop build with the experimental mbedTLS backend enabled (see ORO_ENABLE_MBEDTLS below).
  • Local certificates for the server and client. A helper script is included.

Generate certificates

From the repository root:

bash examples/tls/gencerts.sh

The script creates a local certificate authority along with server and client certificates signed by that CA. You can provide your own certs instead, as long as the server and client trust the same CA bundle.

Run the basic echo server

  1. Start the TLS server: 
    ORO_ENABLE_MBEDTLS=1 oroc run examples examples/tls/server.mjs
  2. Run the client in a separate shell: 
    ORO_ENABLE_MBEDTLS=1 oroc run examples examples/tls/client.mjs

The client writes hello over tls once the secure handshake completes and logs the echoed payload. The example sets rejectUnauthorized: false to accept the self-signed server certificate. For production scenarios always provide a trusted CA bundle and leave rejectUnauthorized enabled.

Mutual TLS (mTLS)

  1. Launch the mTLS server: 
    ORO_ENABLE_MBEDTLS=1 oroc run examples examples/tls/server-mtls.mjs
  2. Connect with the mTLS client: 
    ORO_ENABLE_MBEDTLS=1 oroc run examples examples/tls/client-mtls.mjs

Both peers validate each other using the generated CA. Keep rejectUnauthorized enabled when you supply client certificates so the client can fail fast on untrusted servers.

Inspect handshake events

The server listens for the secureConnectionReady event to confirm the native handshake and logs the clientId. The clients log the payload from secureConnect, which contains negotiated protocol details such as the selected ALPN.

You can open this folder in the bundled example browser to review the scripts alongside the generated certificates. When testing certificate rotation or error handling, remove the generated files and rerun gencerts.sh.
